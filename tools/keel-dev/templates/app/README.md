## Run it on your desktop

From this directory, with Shipwright's `keel` tool:

```
keel run                                  # 540x960 window
keel run --device jolla-c2 --ambience light
keel run --watch                          # restart when a QML file changes
QT_QPA_PLATFORM=offscreen keel run --screenshot first-page.png
```

`keel run` builds the app, checks the QML with keel-compat and starts it
against a Keel build (`--keel-build` or `KEEL_BUILD_DIR`, `--keel-qml` or
`KEEL_QML_DIR`; by default it builds Keel from your Shipwright checkout
into `~/.cache/keel-dev/keel-build`).

## Test

```
export KEEL_BUILD_DIR=<a Keel CMake build>   # not needed after `keel run` built one
cargo test                                   # unit tests (src/greeter.rs)
cargo build && tests/smoke-test.sh           # offscreen: first page, cover
```

`build.rs` links Keel's SailfishApp library from `KEEL_BUILD_DIR`, else
from the Keel build `keel run` keeps in `~/.cache/keel-dev/keel-build`,
else from an installed `shipwright-keel-sailfishapp-devel` (pkg-config
`keel-sailfishapp`).

## Package

Icons: edit `icons/{{name}}.svg`, then `icons/render-icons.sh`
(needs `rsvg-convert`) and commit the PNGs.

Device RPM, in the Sailfish platform SDK container that Shipwright's
`tools/build/sdk/sdk.sh` sets up, with Keel's RPMs built there:

```
SHIPWRIGHT_DIR=<your Shipwright checkout> rpm/build-in-sdk.sh
```

It cross-builds the app with Shipwright's `tools/build/sdk/cxxqt-sailfish.sh`
and runs `mb2 -s rpm/{{name}}.spec build`; RPMs land in `RPMS/<release>/`.
Install on a phone in developer mode with `pkcon install-local` or
`rpm -U` together with the Keel packages (`shipwright-keel-silica`,
`-sailfishapp`, `-shell`) and Chum's Qt 6.

Before publishing on Reef: the package name and binary are the app id
(`{{name}}`), and the Sailjail `Permissions=` line lists what the app uses
(see Shipwright's `docs/developers/porting-guide.md`).
